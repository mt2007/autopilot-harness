# Hosts

Product front door: [README.md](../README.md). Stop-loop internals: [architecture.md](./architecture.md).

Autopilot separates **core** (FSM, SQLite, checklist, review) from **ports** (host adapters). **This build ships Cursor, Claude Code, Codex, Kimi Code, GitHub Copilot CLI, Grok Build CLI, Gemini CLI, Factory Droid, Hermes Agent, Antigravity, Runner (meta), Pi, and Devin CLI** (CLI + App share one Codex hook surface; Kimi is **degraded Stop≤1/turn**; Copilot is **degraded Stop consecutive ≤8**; Grok is **degraded Stop ≤8/turn** — per-turn reset; no raise found; Gemini is **Shipped** with honest **AfterAgent turn cap ≤100** (`MAX_TURNS`; no raise) and soft min-CLI **≥0.31.0**; Factory is **Shipped** with **multi-block under `stop_hook_active` live-proved** — no documented numeric Stop cap / raise knob; **waive live → default degraded≤1**; Hermes is **Shipped** with **shell `pre_verify` continue live-proved** — init raises **`agent.max_verify_nudges` ≥32**; edit-only verify; soft min Hermes **≥0.21.3**; **waive live → degraded + human R1 ack**; Antigravity is **Shipped** (**host Stop continue live-proved** in **0.10.1**) — `NO_TOOL_CALL` + `transcript_full.jsonl` + **`.agents/bin` shim**; CLI must mount workspace; **Runner** is **Shipped (meta)** — external `runner start` loop + public `@autopilot-harness/port-runner`; outside the eleven-way hook stamp set; **Pi** is **Shipped** (**interactive TUI live Stop-continue ≥1× proved**) — in-process `.pi/extensions/autopilot.ts` + vendor runtime; soft min Pi **≥0.85.1**; **`/trust` + `/reload`**; **R10** surface is interactive TUI only (**not** `pi -p` / JSON / print); **not** in shell `KNOWN_PLATFORMS` — matrix stays **eleven-way shell + Pi extension**). Further hosts are on the [roadmap](#roadmap-not-shipped) below (**OpenCode** is **1 (next)** — wait upstream). **Devin CLI** is **Shipped** (**interactive CLI live Stop-continue ≥1× proved** + edit arm; **CLI only** — not Desktop, not cloud Devin, not Cascade).

Installed hook commands stamp **`--platform <id>`** (e.g. `cursor` / `claude-code` / `codex` / `kimi-code` / `copilot-cli` / `grok-build` / `gemini-cli` / `factory-droid` / `hermes-agent` / `antigravity` / `devin`) as the primary dispatch switch (**eleven-way** today). **Pi** is installable (`surface: cli`) but **does not** use a shell `--platform pi` stamp — in-process handlers only (`handlePiInput` / `handlePiBeforeAgentStart` / `handlePiToolResult` / `handlePiAgentSettled`); shell `--platform pi|runner` aborts before FSM. Vendor runtime exports **aliased** Codex, Kimi, Copilot, Grok, Gemini, Factory, Hermes, Antigravity, Devin, and Pi handlers (`handleCodexUserPromptSubmit` / `handleCodexPostToolUse` / `handleCodexStop` / `handleKimiUserPromptSubmit` / `handleKimiPostToolUse` / `handleKimiStop` / `handleCopilotUserPromptSubmit` / `handleCopilotUserPromptTransformed` / `handleCopilotPostToolUse` / `handleCopilotStop` / `handleGrokUserPromptSubmit` / `handleGrokPostToolUse` / `handleGrokStop` / `handleGeminiUserPromptSubmit` / `handleGeminiPostToolUse` / `handleGeminiStop` / `handleFactoryUserPromptSubmit` / `handleFactoryPostToolUse` / `handleFactoryStop` / `handleHermesPreLlmCall` / `handleHermesPostToolCall` / `handleHermesPreVerify` / `handleAntigravityPreInvocation` / `handleAntigravityPostToolUse` / `handleAntigravityStop` / `handleDevinUserPromptSubmit` / `handleDevinPostToolUse` / `handleDevinStop` / `handlePiInput` / `handlePiBeforeAgentStart` / `handlePiToolResult` / `handlePiAgentSettled`). Runtime still applies **universal abort** and a **payload conflict resolver** so IDE cross-fire (Cursor-shaped stdin on a Claude/Codex/Kimi/Copilot/Grok/Gemini/Factory/Hermes/Antigravity/Devin-stamped command) cannot recover into the wrong host continue shape.

## Roadmap (not shipped)

## Subagents (neutral policy + tiers)

Autopilot **does not** tell the agent to open or avoid subagents / Task workers. Each host and agent decides during execution. Skills, workflows, and stop followups stay **neutral** on that choice.

When a subagent **does** edit product code, Autopilot still wants fix→confirm→advance to finish on the **parent** track. Support is **tiered** by host capability (not by preference):

| Tier | Hosts (this build) | What Autopilot does | Honest limit |
|------|--------------------|---------------------|--------------|
| **Tier-S** | **Cursor**, **Claude Code** | **0.17+:** install `subagentStop` / `SubagentStop`; attribute parent when payload names a **pre-existing** parent session; edit hooks with parent → arm parent; subagent stop **arms only** (no followup / no block-continue); review on **parent** stop | Cursor **background** subagents may never fire `subagentStop`; empty `modified_files` → git dirty probe; no parent / missing parent session → **no-op** (does not invent sessions) |
| **Tier-B** | Codex, Kimi, Copilot, Grok, Gemini, Factory, Hermes, Antigravity, Devin, … | **No** fake SubagentStop wiring (host has no usable event). Rely on parent **stop dirty-arm** + normal edit hooks when they share the parent session id | If a child runs in an isolated session with no parent stop dirty path, closeout is **best-effort only** — do not claim Tier-S parity |
| **Tier-N** | Hosts / surfaces with little or no delegation (e.g. some CLI-only flows, Runner meta loop) | N/A — no subagent lifecycle to bridge | Neutrality still applies; nothing to arm |

**Do not** read Tier-S as “please use subagents.” It only means: if the host fires those events, Autopilot can keep the parent review chain coherent.

## Stop-loop caps (why ports matter)

Fix + multi-lens confirm needs many consecutive stop continuations. Each host has its own circuit breaker; ports must disable or raise it **when possible**. If the host **hard-caps** continuations **below a usable Autopilot review chain** (e.g. Kimi ≤1 / turn, Copilot consecutive ≤8, Grok ≤8 / turn), ship **degraded** Autopilot (keep the stop streak short — for Kimi, recommend `confirm_rounds: 1`; for Copilot/Grok, expect mid-chain cutoffs and recover via pending / RESUME / nudge) — otherwise the chain stalls mid-confirm (pending followup left in DB). Caps that still cover worst-case fix+confirm (e.g. Gemini host **`MAX_TURNS` ≤100**) ship full Autopilot with an honest documented ceiling — not the degraded pattern.
