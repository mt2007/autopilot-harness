# Hosts

Product front door: [README.md](../README.md). Stop-loop internals: [architecture.md](./architecture.md).

Autopilot separates **core** (FSM, SQLite, checklist, review) from **ports** (host adapters). **This build ships Cursor, Claude Code, Codex, Kimi Code, GitHub Copilot CLI, Grok Build CLI, Gemini CLI, Factory Droid, and Hermes Agent** (CLI + App share one Codex hook surface; Kimi is **degraded Stop≤1/turn**; Copilot is **degraded Stop consecutive ≤8**; Grok is **degraded Stop ≤8/turn** — per-turn reset; no raise found; Gemini is **Shipped** with honest **AfterAgent turn cap ≤100** (`MAX_TURNS`; no raise) and soft min-CLI **≥0.31.0**; Factory is **Shipped** with **multi-block under `stop_hook_active` live-proved** — no documented numeric Stop cap / raise knob; **waive live → default degraded≤1**; Hermes is **Shipped** with **shell `pre_verify` continue live-proved** — init raises **`agent.max_verify_nudges` ≥32**; edit-only verify; soft min Hermes **≥0.21.3**; **waive live → degraded + human R1 ack**). Further hosts are on the [roadmap](#roadmap-not-shipped) below.

Installed hook commands stamp **`--platform <id>`** (e.g. `cursor` / `claude-code` / `codex` / `kimi-code` / `copilot-cli` / `grok-build` / `gemini-cli` / `factory-droid` / `hermes-agent`) as the primary dispatch switch (**nine-way** today). Vendor runtime exports **aliased** Codex, Kimi, Copilot, Grok, Gemini, Factory, and Hermes handlers (`handleCodexUserPromptSubmit` / `handleCodexPostToolUse` / `handleCodexStop` / `handleKimiUserPromptSubmit` / `handleKimiPostToolUse` / `handleKimiStop` / `handleCopilotUserPromptSubmit` / `handleCopilotUserPromptTransformed` / `handleCopilotPostToolUse` / `handleCopilotStop` / `handleGrokUserPromptSubmit` / `handleGrokPostToolUse` / `handleGrokStop` / `handleGeminiUserPromptSubmit` / `handleGeminiPostToolUse` / `handleGeminiStop` / `handleFactoryUserPromptSubmit` / `handleFactoryPostToolUse` / `handleFactoryStop` / `handleHermesPreLlmCall` / `handleHermesPostToolCall` / `handleHermesPreVerify`) so they never collide with Claude’s bare names. Runtime still applies **universal abort** and a **payload conflict resolver** so IDE cross-fire (Cursor-shaped stdin on a Claude/Codex/Kimi/Copilot/Grok/Gemini/Factory/Hermes-stamped command) cannot recover into `decision:block`.

`platforms` in `.autopilot/config.yml` lists enabled hosts (`id` + `surface`: `ide` \| `cli` \| `runner`). This build installs **Cursor**, **Claude Code**, **Codex**, **Kimi Code**, **GitHub Copilot CLI**, **Grok Build CLI**, **Gemini CLI**, **Factory Droid**, and/or **Hermes Agent** when those bindings are present; listing other future ids in config does not invent a missing port. **Runner** (and other roadmap hosts) are roadmap markers only — `init` / `--add-platform` do **not** install them yet (stubs under `packages/ports/`). Multi-host among shipped hosts: `init --yes --add-platform <id>` after the first host is wired. **Concurrency note:** enabling installable `kimi-code` **clamps `review.confirm_rounds` to 1 for the whole project** (not only Kimi turns). Copilot, Grok, Gemini, Factory, and Hermes do **not** clamp rounds. Copilot hooks live in **project** `.github/hooks/autopilot-harness.json` (default `.autopilotignore` includes `.github/hooks/**`). Grok hooks live in **project** `.grok/hooks/autopilot-harness.json` (default `.autopilotignore` includes `.grok/hooks/**`; siblings kept; empty fingerprint unlinked). Gemini hooks live in **project** `.gemini/settings.json` (default `.autopilotignore` includes `.gemini/settings.json`; foreign top-level keys / `hooksConfig` kept). Factory hooks live in **project** `.factory/hooks.json` (default `.autopilotignore` includes `.factory/hooks.json`; siblings kept; empty fingerprint unlinked; commands use **`$FACTORY_PROJECT_DIR`**; init/upgrade **refuse symlink** `.factory/` / hooks.json). ## Roadmap (not shipped)

Autopilot needs three capabilities on a host: **prompt/submit** (ON/RUN), **edit/post-tool** (arm review), and **stop-continue** (inject the next fix/confirm followup). Hosts with **no** usable stop-continue belong under **Runner**. Future hosts with only a **hard-capped** stop-continue **too small for a full review chain** may still ship as a **degraded hook port** (same pattern as shipped Kimi ≤1/turn, Copilot consecutive ≤8, and Grok ≤8/turn) — document the cap; do not claim full multi-lens streaks. Adequate ceilings (as with Gemini **`MAX_TURNS` ≤100**) ship full Autopilot with an honest documented cap instead.

### Recommended order

| Priority | Host | Fit | Why this order |
|---------:|------|-----|----------------|
| **1 (next)** | **Antigravity** | Medium | `.agents/hooks.json` / `~/.gemini/config/hooks.json` with `PreToolUse` / `PostToolUse` / `Stop`. Confirm Stop can **inject continue** (not observe-only) before committing a port. |
| **2** | **OpenCode** | Medium–Low | Extensibility is **plugin**-centric; first-party Stop-continue is weaker than Claude/Codex. Community Claude-compat plugins exist but are partial — prefer waiting for a stable first-party contract or use Runner. |
| **3** | **Runner** | Meta | Catch-all for hosts that cannot stop-continue (or when we want one external loop). Stub exists; ship after at least one more native hook port **or** when targeting a no-hooks host. |
| — | **Pi** | Research | In-process JS/TS hook factories / event bus — different packaging model than shell-stdin ports. |
| — | **Devin CLI** | Research / low | Cloud/agent product surface; local hook dogfood and durable project wiring are unclear. Prefer Runner or skip until a documented local hook API exists. |

## Stop-loop caps (why ports matter)

Fix + multi-lens confirm needs many consecutive stop continuations. Each host has its own circuit breaker; ports must disable or raise it **when possible**. If the host **hard-caps** continuations **below a usable Autopilot review chain** (e.g. Kimi ≤1 / turn, Copilot consecutive ≤8, Grok ≤8 / turn), ship **degraded** Autopilot (keep the stop streak short — for Kimi, recommend `confirm_rounds: 1`; for Copilot/Grok, expect mid-chain cutoffs and recover via pending / RESUME / nudge) — otherwise the chain stalls mid-confirm (pending followup left in DB). Caps that still cover worst-case fix+confirm (e.g. Gemini host **`MAX_TURNS` ≤100**) ship full Autopilot with an honest documented ceiling — not the degraded pattern.

| **Codex** | Stop block + `reason` as next prompt; `stop_hook_active` | No documented numeric cap (2026-09 research) | **Shipped** hook port: `.codex/hooks.json` + `/hooks` trust (re-trust after changes); omit timeout or ≥120s. Measure long chains in live smoke when Codex is available. |
| **Kimi Code** | Blockable `Stop`; **≤1 continue / turn** (hard cap in agent-core) | Default hook timeout often **30s** | **Shipped** degraded port: timeout ≥120s; doctor WARN Stop-cap + short timeout; prefer `confirm_rounds: 1` (hook clamps to `1`). |

Submit / edit hooks (and Claude/Codex/Kimi/Copilot/Grok/Gemini/Factory/Hermes submit analogues — `UserPromptSubmit` / `userPromptSubmitted` / `BeforeAgent` / `pre_llm_call`) are **not** subject to Cursor’s stop `loop_limit`.

## Not bridged (yet)

Host-native **Plan modes** (Cursor Plan Mode, Claude Code Plan mode, etc.) are separate from Autopilot grill and `review.scope`. Autopilot does not currently map those modes onto ON / RUN / review. Codex `permission_mode: plan` is ignored by the port.

Design sketch and acceptance criteria for a future optional bridge: [host-plan-bridge.md](./host-plan-bridge.md).
