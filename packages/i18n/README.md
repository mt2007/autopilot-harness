# @autopilot-harness/i18n

Locale strings for Autopilot (`en`, `zh-CN`) used by the CLI and stop-hook followups.

Most users should install **[`@autopilot-harness/cli`](https://www.npmjs.com/package/@autopilot-harness/cli)** instead of depending on this package directly.
