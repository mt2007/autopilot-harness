# @autopilot-harness/port-cursor

Cursor host adapter for Autopilot (hook payload shaping and related port code).

Most users should install **[`@autopilot-harness/cli`](https://www.npmjs.com/package/@autopilot-harness/cli)** instead of depending on this package directly. Consumer projects get a vendored hook runtime via `init`; they do not need to import this package by hand.
